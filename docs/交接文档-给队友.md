## 2. 三条硬约束（动手前务必知道）

这个项目要满足作业要求「**下载后用谷歌浏览器打开 html 就能跑**」，
所以刻意做成了**零依赖纯静态站点**，代价是三条限制：

1. **不能用 ES module。** `file://` 下 Chrome 会按 CORS 拦掉 `<script type="module">`。
   → 全站只用传统 `<script src="js/xxx.js">`，按顺序引入。
2. **不能 `fetch` 读本地 JSON。** 同样被拦。
   → 所有数据要么在 `.js` 里赋值给全局变量，要么走 `LF.store`。
3. **所有 HTML 必须放在仓库根目录。** 数据里存的图片路径形如 `assets/items/item-01.svg`，
   如果页面放进 `detail/index.html`，这个相对路径会解析成 `detail/assets/...` 而 404。
   → 所以是 `detail.html` 而不是 `detail/index.html`，**请沿用这个平铺结构**。

还有一个隐性约束：**文件名不能改**。它们已经被别处硬编码链接了：

| 文件名 | 谁在链它 |
| --- | --- |
| `detail.html?id=<id>` | `js/card.js` 里每张卡片默认的跳转目标 |
| `search.html` `square.html` `mine.html` | `js/layout.js` 的底部 TabBar |
| `square.html?kind=found` `?kind=lost` | `index.html` 的两个大入口卡 |
| `square.html` | `index.html` 的「查看全部 >」 |
| `mine.html` | `publish-done.html` 的「查看我的发布」 |

## 3. 接口手册（本节是核心，随时来查）

### 3.1 数据模型：一条信息长这样

```js
{
  id: 'LF-20260928-001',          // string  唯一 ID，由 store 自动生成，格式 LF-YYYYMMDD-序号
  kind: 'lost',                   // 'lost' 寻物 | 'found' 招领
  title: '黑色 Sony 降噪耳机',      // string  物品名称，必填，≤40 字
  category: 'digital',            // string  物品类别，必填，取值见下表
  place: '图书馆三楼 C 区自习室',    // string  地点，选填，自由文本
  happenedAt: '2026-09-28T14:20', // string  丢失/拾到时间，选填
  desc: '……',                     // string  详细描述，选填，≤200 字
  images: ['assets/items/item-01.svg'],  // string[]  选填
  contact: { type: 'phone', value: '138-0013-8000' },  // 必填
  state: 'open',                  // 'open' 进行中 | 'done' 已完成  ← 唯一的状态真相
  author: { name: '小白同学', college: '计算机学院', grade: '2023级' },
  createdAt: '2026-09-28T14:20:00.000Z',  // 发布时间
  updatedAt: '2026-09-28T14:20:00.000Z',
  timeline: [ { state: 'open', at: '…' }, { state: 'done', at: '…' } ]
}
```

**类别取值**（用 `LF.CATEGORIES` 遍历拿，别手写中文）：

| id | label |
| --- | --- |
| `card` | 证件卡片 |
| `digital` | 数码电子 |
| `keychain` | 钥匙·挂件 |
| `bag` | 服饰包袋 |
| `stationery` | 书籍文具 |
| `other` | 其他小物 |

**联系方式类型**（`LF.CONTACT_TYPES`）：`phone` 手机 / `wechat` 微信 / `qq` QQ。

**状态只有两个值**，页面上显示的中文由函数派生，不要自己写字符串：

| | `state: 'open'` | `state: 'done'` |
| --- | --- | --- |
| `kind: 'lost'`（寻物） | 焦急寻找中（橙） | 已找到（蓝） |
| `kind: 'found'`（招领） | 寻找失主中（绿） | 已归还（蓝） |

### 3.2 `LF.*` 纯函数（`js/core.js`）

> 全部是纯函数：不进 DOM、不碰存储、不改入参。**页面和单元测试跑的是同一份代码。**

```js
// —— 常量 ——
LF.CURRENT_USER      // { name:'小白同学', college:'计算机学院', grade:'2023级' }
LF.KINDS             // { lost:'寻物', found:'招领' }
LF.CATEGORIES        // [{ id:'card', label:'证件卡片' }, ...] 共 6 项
LF.CONTACT_TYPES     // [{ id:'phone', label:'手机', hint:'如：138-0013-8000' }, ...]
LF.TITLE_MAX         // 40
LF.DESC_MAX          // 200

// —— 文本 ——
LF.escapeHtml(v)             // '→ string   转义 & < > " '   ！！凡是用户输入拼进 innerHTML 都必须过它
LF.trim(v)                   // '  a ' → 'a'，null/undefined → ''
LF.categoryLabel('digital')  // '数码电子'，未知返回 ''
LF.contactTypeLabel('phone') // '手机'
LF.kindLabel(item)           // '寻物' | '招领'

// —— 状态 ——
LF.statusText(item)          // '焦急寻找中' | '寻找失主中' | '已找到' | '已归还'
LF.toneOf(item)              // 'orange' | 'green' | 'blue'   ← 直接当 class 后缀：class="pill is-orange"
LF.isMine(item)              // bool  是不是当前用户发的
LF.canTransit(item)          // bool  能不能标记完成（= 本人发 && state==='open'）
LF.markDone(item, isoNow?)   // 新对象（不改原对象），state→'done' 并追加 timeline

// —— 校验与补全（发布页在用，你一般用不到）——
LF.validateDraft(draft)      // { ok:bool, errors:{ title?, category?, desc?, contact? } }
LF.normalizeDraft(draft, at) // 补上 state/createdAt/timeline，trim 各字段

// —— 检索 ★ 搜索页和广场页的主力 ——
LF.search(items, query)      // 筛选 + 按时间倒序，返回新数组（不动入参），永远返回数组不会 null
LF.matchesQuery(item, query) // bool，单条判断
LF.sortByTime(items, dir?)   // 'desc'(默认) | 'asc'，返回新数组

// —— 时间 ——
LF.formatTime(iso, now?)     // '今天 14:20' | '昨天 19:00' | '前天 08:30' | '09-28 14:20'；非法输入返回 ''
LF.formatRelative(iso, now?) // '刚刚' | '12 分钟前' | '2 小时前' | '3 天前'；非法返回 ''

// —— ID ——
LF.nextId(items, now?)       // 'LF-20261007-001'（同一天内取最大序号 +1）
```

**`LF.search` 的 `query` 参数**（每个字段都可以不传或传 `'all'`，表示该项不筛选）：

```js
LF.search(items, {
  keyword:  '耳机',       // 在 标题 / 地点 / 描述 / 类别名 里做子串匹配，不区分大小写
  kind:     'found',      // 'lost' | 'found' | 'all'
  category: 'digital',    // 上面那张类别表的 id | 'all'
  place:    '图书馆',      // 地点的子串匹配（'图书馆' 能命中 '图书馆三楼 C 区'）
  state:    'open'        // 'open' | 'done' | 'all'
})
```

用法示例：

```js
var items = LF.store.all();
var hit = LF.search(items, { keyword: '耳机', category: 'digital' });
```

### 3.3 `LF.store.*` 数据层（`js/store.js`）

> 页面**只通过它读写数据**，不要自己去碰 `localStorage`。
> 数据存在 `localStorage` 的 `shiguang.items.v1` 键下；首次打开自动灌入 9 条种子数据。

```js
LF.store.persistent        // bool  localStorage 是否可用（不可用时已自动降级为内存，页面照常跑）
LF.store.all()             // item[]  全部信息（**返回副本**，你改它不会影响存储）
LF.store.get(id)           // item | null
LF.store.add(draft, now?)  // item | null   校验不过返回 null
LF.store.markDone(id, now?)// item | null   非本人 / 已标记过 返回 null（标记不可逆）
LF.store.remove(id)        // bool
LF.store.reset(now?)       // item[]  恢复种子数据（「我的」页放个「重置演示数据」按钮很有用）
LF.store.stats(user?)      // { total, open, done }  默认统计当前用户的发布
```

典型写法：

```js
// 广场页
var list = LF.store.all();
LF.card.renderList(document.getElementById('list'), LF.search(list, { kind: 'found' }));

// 「我的」页
var mine = LF.store.all().filter(function (i) { return LF.isMine(i); });
var s = LF.store.stats();     // { total: 3, open: 2, done: 1 }
```

### 3.4 `LF.card.*` 卡片渲染（`js/card.js`）

> 首页、搜索、广场、我的**四处共用同一个卡片**，别自己重写 HTML，否则四页长得不一样。

```js
LF.card.render(item, options?)     // → DOM 元素
LF.card.renderList(container, items, options?)   // 清空容器再批量渲染，返回渲染条数
LF.card.timeLine(item)             // '今天 14:20 拾到'
LF.card.FALLBACK_IMG               // 图片加载失败时的内联 SVG（不联网）
```

`options`：

| 字段 | 说明 |
| --- | --- |
| `variant` | `'row'`（默认，单列横向卡片，首页在用）或 `'stack'`（双列网格卡片，适合广场/搜索结果） |
| `href` | 不传 = 默认跳 `detail.html?id=<id>`；传 `null` = **不可点**（「我的」页要自己绑点击时用） |
| `badge` | 传 `false` 可隐藏左上角的「寻物/招领」角标 |

```js
// 广场页：双列网格
LF.card.renderList(el, items, { variant: 'stack' });

// 搜索结果：单列，和首页一致
LF.card.renderList(el, items);

// 「我的」页：卡片本身不可点，点击由我自己接管
var card = LF.card.render(item, { href: null });
card.addEventListener('click', function () { /* ... */ });
```

### 3.5 `LF.layout.*` 页面外壳（`js/layout.js`）

新页面照抄这个骨架，顶栏和底部 TabBar 会自动注入，**不用自己写**：

```html
<div class="app" data-shell="back" data-tab="search" data-title="搜索">
  <div data-layout="header"></div>
  <main class="page">
    <!-- 你自己的内容 -->
  </main>
  <div data-layout="tabbar"></div>
</div>

<script src="js/core.js"></script>
<script src="js/seed.js"></script>
<script src="js/store.js"></script>
<script src="js/layout.js"></script>
<script src="js/card.js"></script>
<script>LF.layout.init();</script>
```

`data-shell`：

- `brand` —— 首页那种「头像 + 拾光校园 + 菜单」的顶栏
- `back` —— 子页面那种「← + 标题」，标题取 `data-title`（搜索/广场/详情/我的都用这个）

`data-tab`：`home` | `search` | `square` | `mine` | `none`
（`none` = 这一页不显示底部 TabBar，比如详情页；填对了对应项会自动高亮）

可调用的函数：

```js
LF.layout.init()             // 每页调一次：填顶栏、填 TabBar、挂弹层和全局事件
LF.layout.toast('已复制')     // 底部轻提示，1.8 秒后自动消失
LF.layout.copyText('138...') // → Promise<bool>  复制到剪贴板（已自动处理 file:// 的兼容问题）
LF.layout.openPostChoice()   // 打开「发布寻物 / 发布招领」选择弹层
LF.layout.closePostChoice()
LF.layout.tabbar('square')   // 生成底部栏 HTML 字符串（一般用不到，init() 会处理）
```

**两个白拿的全局能力**（`init()` 已挂好，你只要写属性）：

```html
<!-- 点一下就复制并弹「已复制」提示 -->
<button data-copy="138-0013-8000">📋 复制手机号</button>

<!-- 返回上一页（详情页顶栏用） -->
<button data-action="back">返回</button>
```

## 6. 你要做的四个页面 + 两个收尾

> **对照物**：用 Chrome 打开仓库里的 **`docs/原型参照.html`**（就在你 clone 下来的目录里，双击不用，
> 右键 → 打开方式 → Google Chrome）。里面是 16 张原型画板（`01-首页` … `13-空状态` + 3 个弹窗）。
> 左窗口放原型、右窗口放你自己写的页面，对着调到像为止 —— 这也是作业评分里「美观性」的来源。

### 6.1 `search.html` 搜索页 —— 对应原型 `08-搜索`、`09-搜索结果`

**做什么**

1. 顶部一个真输入框（`.form-input`），占位文字「搜索丢失物品、地点」，输入即筛选（`input` 事件）
2. 下方筛选区：
   - 类型分段：全部 / 寻物 / 招领 → `.segmented`
   - 类别 chips：全部 + 6 个类别 → 遍历 `LF.CATEGORIES` 生成 `.chips > .chip`
3. 结果列表用 `LF.card.renderList(el, hit)`
4. 输入框为空时显示「最近发布」或热门关键词；搜索无结果时显示空状态

**关键代码**

```js
function update() {
  var hit = LF.search(LF.store.all(), {
    keyword:  input.value,
    kind:     currentKind,        // 'all' | 'lost' | 'found'
    category: currentCategory     // 'all' | 'card' | ...
  });
  if (!hit.length) { showEmpty(); } else { LF.card.renderList(listEl, hit); }
}
input.addEventListener('input', update);
```

**注意**：`LF.search` 已经做了「排序 + 返回副本」，你不用再排序。

### 6.2 `square.html` 广场页 —— 对应原型 `10-广场`

**做什么**

1. 读 `?kind=` 决定初始筛选（`lost` / `found` / 不传 = 全部）
2. 顶部 `.segmented` 让用户手动切换 全部 / 寻物 / 招领
3. 列表用 **`.item-grid` + `variant:'stack'`** 做成双列瀑布，和首页的单列区分开
4. 切换筛选时**用 `history.replaceState` 同步 URL**，这样刷新后筛选状态还在

**注意**：`index.html` 已经用 `square.html?kind=found` 和 `?kind=lost` 链过来了，
所以 `?kind=` 必须支持，否则首页两个大入口点进去是错的。

### 6.3 `detail.html` 详情页 —— 对应原型 `11-信息详情`、`弹窗-联系拾到者`

**做什么**

1. 读 `?id=`，`LF.store.get(id)` 取数据；**取不到就显示「信息不存在」空状态**，不要白屏
2. 展示全部字段：类型角标、标题、状态、类别、地点、丢失/拾到时间、详细描述、图片
3. **发布者卡片**：头像 + 姓名 + 学院年级 + 用 `LF.formatRelative(item.createdAt)` 显示「2 小时前发布」
4. **联系方式区** —— 这是作业明确要求的「查看发布者提供的联系方式」：
   ```html
   <button class="btn btn-primary btn-block" data-copy="138-0013-8000">
     📋 复制手机号 138-0013-8000
   </button>
   ```
   `data-copy` 是 `js/layout.js` 已经接好的全局能力，**点一下自动复制并弹「已复制」**，你不用写任何 JS。

## 7. 我踩过的坑（你不用再踩一遍）

1. **`<script type="module">` 在 `file://` 下必炸。** 报 CORS 错，页面一片空白。全站只能用传统 `<script src>`。
2. **`fetch('./data.json')` 在 `file://` 下必炸。** 同样被拦。所以种子数据是 `js/seed.js`（赋值给全局），不是 `.json`。
3. **页面放进子目录会让图片 404。** 数据里存的是 `assets/items/xx.svg` 这种相对路径，
   从 `detail/index.html` 解析会变成 `detail/assets/...`。**所以 HTML 一律平铺在根目录。**
4. **绝对定位元素不参与 CSS Grid 自动排布。** 底部那个「＋」用了 `position:absolute`，
   如果不给它留一个空的 `.tab-slot` 占位格，后面的「广场」标签会被挤出第 5 格看不见 —— **`.tab-slot` 别删**。
5. **localStorage 可能在 `file://` 下不可用**（隐私设置、无痕模式）。`js/store.js` 已经做了探测和内存兜底，
   你只要在页面上提示一句就行（首页有现成的写法：`if (!LF.store.persistent) console.warn(...)`）。
6. **`--screenshot` 要绝对路径**（如果你也用 headless Chrome 截图自检的话）。
   另外 Windows 上 headless Chrome 有**最小窗口宽度（约 500px）**，
   你设 `--window-size=430,932` 会得到「按 500 排版、按 430 裁剪」的右侧被切掉的图 —— 那是截图的问题，不是页面坏了。用 600 宽拍。
7. **headless Chrome 的路径**：`C:/Program Files/Google/Chrome/Application/chrome.exe`。
